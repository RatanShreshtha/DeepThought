# Deep Thought

A blog theme for the Zola static site generator, focused on writing and built on Bulma. Sites that use it get posts, documentation, taxonomies, and embeddable media out of the box.

## Language

**Deep Thought**:
The theme itself. "DeepThought" is used only for the repository and package name.
_Avoid_: Template, skin, DeepThought (as a product name)

**Site**:
A Zola website that uses Deep Thought as its theme.
_Avoid_: Blog, project

**Page**:
A single piece of authored content with a title, optional date, and optional taxonomy terms.
_Avoid_: Article, entry

**Section**:
A group of Pages listed together under one navbar entry, such as Posts or Docs.
_Avoid_: Collection, folder

**Post**:
A Page in the Posts Section. Not structurally different from any other Page.
_Avoid_: Article, blog entry

**Doc**:
A Page in the Docs Section. Not structurally different from any other Page.
_Avoid_: Documentation page, guide

### Classification

**Category**:
A taxonomy for classifying Pages. Parallel to Tag; the theme gives it no special meaning.
_Avoid_: Topic, group

**Tag**:
A taxonomy for classifying Pages. Parallel to Category; the theme gives it no special meaning.
_Avoid_: Label, keyword

### Embedded content

**Component**:
A snippet an author writes in Markdown to embed rich content such as a chart, diagram, map, gallery, math, or video.
_Avoid_: Shortcode (the Zola feature it replaced), embed, widget

**Extension**:
A Component capability that a Site must switch on before its supporting assets are loaded.
_Avoid_: Plugin, module

### Site identity

**Author**:
The single person a Site presents as the writer of all its Pages. A Site has exactly one.
_Avoid_: Writer, user, owner

**Social links**:
The set of the Author's profiles on other services, shown on the home and not-found pages.
_Avoid_: Social media, contacts

**Search**:
Full-text lookup over a Site's Pages, opened from the Navbar and built per language.
_Avoid_: Find, filter

**Navbar**:
The top navigation, made of items defined per language.
_Avoid_: Menu, header
